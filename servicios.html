¿Cómo Funciona el Sistema?

01

Canal de Venta WhatsApp

Tus clientes te escriben por WhatsApp Business. El sistema captura cada mensaje automáticamente.

02

Procesamiento n8n

n8n procesa y transforma los datos en tiempo real, estructurando toda la información.

03

IA con Flowise

Flowise LLM analiza y responde inteligentemente, personalizado para tu negocio.

04

Backend Supabase

Toda la información se almacena de forma segura y accesible en tiempo real.

05

Formulario Web

Captura pedidos desde tu sitio web integrado al sistema.

Gestión Visual

Panel tipo Trello donde visualizas y gestionas todos los pedidos.
